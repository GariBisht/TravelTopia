Anime.js was first released in 2016, created by Julian Garnier. It's been a popular lightweight animation tool ever since, especially for web developers working with CSS, SVG, or JavaScript animations.

🎌 Anime.js – Smooth JavaScript Animations, Simplified

If you're looking to create smooth, powerful, and easy-to-control animations in your web app, Anime.js is a fantastic option. It supports CSS properties, DOM attributes, SVG, and even JavaScript object values.

📦 Installation

You can install it using npm:

bash
npm install animejs

Or drop it via CDN for quick testing:

html
<script src="https://cdnjs.cloudflare.com/ajax/libs/animejs/3.2.1/anime.min.js"></script>

🚀 Basic Animation Example

Let's animate a box by moving it, rotating it, and changing its color.

html
<div class="box"></div>

<style>
  .box {
    width: 100px;
    height: 100px;
    background-color: crimson;
    margin: 50px;
  }
</style>

<script>
  anime({
    targets: '.box',            // target DOM element
    translateX: 250,            // move 250px on the X-axis
    rotate: '1turn',            // rotate 360 degrees
    backgroundColor: '#00f',    // change background color
    duration: 2000              // run the animation over 2 seconds
  });
</script>

📝 Explanation:

  • targets: Selects the element(s) to animate.

  • translateX, rotate, backgroundColor: These are properties being animated.

  • duration: Time in milliseconds.

⏱ Timeline Animation

You can chain multiple animations using Anime.js timelines. This is super useful for sequential effects.

js
const tl = anime.timeline({
  easing: 'easeOutExpo',
  duration: 750
});

tl.add({
  targets: '.box',
  translateX: 250
}).add({
  targets: '.box',
  translateY: 150
}).add({
  targets: '.box',
  scale: 1.5
});

📝 Explanation:
Each .add() creates a new step in the timeline. Animations run one after another, not simultaneously, unless specified.

🌈 Easing Options

Easing defines how the animation progresses over time (linear, bounce, springy, etc.).

js
anime({
  targets: '.box',
  translateX: 250,
  easing: 'easeInOutQuad' // starts slow, speeds up, then slows down
});

🔁 Looping & Direction

Add looping or reverse direction to your animations easily.

js
anime({
  targets: '.box',
  translateX: 250,
  direction: 'alternate', // forward then backward
  loop: true              // infinite loop
});

🤹‍♂️ Staggered Animations

Great for list items, grids, etc.

js
anime({
  targets: '.box',
  translateY: 100,
  delay: anime.stagger(200) // delay each element by 200ms
});

🧠 Final Thoughts

Anime.js is perfect when you need more control than CSS animations but don’t want the bulk of full animation frameworks. It’s ideal for small UI touches, loading animations, and more.
